# タコスシリーズ LINEスタンプ 分割素材

`ChatGPT Image ...png`（4×4 の1枚絵）を 1 スタンプずつ 16 分割したもの。

- `1` / `2` / `3` … 既に手作業で分割済みだったものをそのまま収録
- `4` 〜 `11筋トレ` … `scripts/split_line_stamps.py` で分割

## 分割の仕様

- アルファチャンネルの行/列投影から格子の区切りを自動検出し、4×4 に分割
- 各セルはセリフを含めて余白なしで切り出し
- LINE スタンプの規定サイズ（横 80〜370px / 縦 80〜320px）に収まるよう縮小
- 周囲に 10px の透過余白を付与し、縦横とも偶数ピクセルに調整

## 実行方法

```sh
python3 scripts/split_line_stamps.py "<1枚絵.png>" "<出力ディレクトリ>"
```

## 注意

`1/2.png` `1/3.png` `1/15.png` `2/1.png` は手作業分のため縦が 320px を超えている。
LINE に登録する際は縦 320px 以内に縮小する必要がある。
