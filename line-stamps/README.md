# LINEスタンプ 分割素材

`ChatGPT Image ...png`（4×4 の1枚絵）を 1 スタンプずつ 16 分割したもの。

- `タコスシリーズ/1` 〜 `3` … 元々手作業で分割済みだったもの（規定サイズに調整済み）
- それ以外 … `scripts/split_line_stamps.py` で分割

キャラクターごとにディレクトリを分けている。

| シリーズ | キャラクター | 内容 |
| --- | --- | --- |
| `タコスシリーズ/1`〜`14` | タコス | 日常・季節・推し活・ゲーミング・筋トレ・敬語など |
| `サボテンシリーズ/サボテン1`〜`2` | サボテン | 日常あいさつ / 敬語 |
| `フクロウシリーズ/フクロウ1`〜`3` | フクロウ（現場作業員） | 現場作業 / あいさつ＋安全 / 日常あいさつ |
| `絵文字シリーズ/タコス絵文字1` | タコス（絵文字） | 40個 |
| `絵文字シリーズ/タコス絵文字2` | タコス（絵文字・淡い絵柄） | 35個 |
| `絵文字シリーズ/タコス絵文字3` | タコス（絵文字・淡い絵柄） | 35個 |

タコスの `12`（敬語）`13`（ゲーミング）`14`（筋トレ）は `7` `10ゲーミング` `11筋トレ` と同テーマの別絵柄。

## LINE Creators Market の規定

**スタンプ**（1パッケージ 8〜40個 / 連番は2桁）

| 画像 | サイズ |
| --- | --- |
| スタンプ画像 | 横 80〜370px / 縦 80〜320px |
| main.png | 240 × 240px |
| tab.png | 96 × 74px |

**絵文字**（1パッケージ 8〜40個 / 連番は**3桁** `001.png`〜）

| 画像 | サイズ |
| --- | --- |
| 絵文字画像 | 180 × 180px 固定（余白をつけず画像いっぱいに） |
| main.png | 240 × 240px |
| tab.png | 96 × 74px |

いずれも縦横とも**偶数ピクセル**の透過 PNG。ZIP は 20MB 以下。

## スクリプト

```sh
# 1枚絵を16分割する（スタンプ / 4x4）
python3 scripts/split_line_stamps.py "<1枚絵.png>" "<出力ディレクトリ>"

# 1枚絵を40分割する（絵文字 / 8x5・180x180）
python3 scripts/split_line_stamps.py "<1枚絵.png>" "<出力ディレクトリ>" --grid 8x5 --emoji

# main.png / tab.png（絵文字はセリフがないので --no-caption）
python3 scripts/make_main_tab.py "<出力ディレクトリ>/001.png" --no-caption

# 既存の画像を規定サイズ・偶数pxに揃える
python3 scripts/normalize_line_stamps.py line-stamps/タコスシリーズ/*/

# main.png / tab.png を作る（元にするスタンプを指定）
python3 scripts/make_main_tab.py line-stamps/タコスシリーズ/4/14.png

# 「ZIPファイル アップロード」用の ZIP を作る（絵文字は --emoji）
python3 scripts/pack_line_stamps.py line-stamps/upload line-stamps/*/*/
```

`line-stamps/upload/` の ZIP は直下に `main.png` `tab.png` `01.png`〜`16.png` を並べた形式で、
マイページの「ZIPファイル アップロード」にそのまま投げられる（スタンプ個数は **16個** を選択）。
ZIP 名はディレクトリ名がそのまま使われるので、ディレクトリ名は全シリーズで重複させないこと。
生成物のためリポジトリには含めていない。スクリプトで作り直せる。

## 分割の仕様

- アルファチャンネルの投影から格子の区切りを自動検出して分割。
  列の区切りは行ごとに検出する（行ごとに横位置がずれている1枚絵があるため）
- 隣のコマの効果線が触れて完全な空白にならない場合は、閾値を少しずつ緩めて探し直す
  （コマ1つ分に対して極端に細い帯は絵の隙間なので除く）
- コマの間に置かれた音符やキラキラは、連結成分ごとに一番近いキャラクターへ割り当てる。
  矩形で切るだけだと隣のコマに破片が混ざるため
- 各セルはセリフを含めて余白なしで切り出し
- 規定サイズに収まるよう縮小し、周囲に 10px の透過余白を付与
- 縦横が奇数になる場合は透過ピクセルを 1px 足して偶数に揃える（絵柄は再サンプリングしない）

## main.png / tab.png

`main` はセリフ込みの全体、`tab` は 96×74px と小さくて文字が潰れるため、
セリフとイラストの間のほぼ空の行を検出してイラスト部分だけを使っている。

どのスタンプを元にしたかは `main-tab-sources.tsv` に記録している。まとめて作り直すには:

```sh
while IFS=$'\t' read -r dir n; do
  python3 scripts/make_main_tab.py "line-stamps/$dir/$n.png"
done < line-stamps/main-tab-sources.tsv
```

セリフとイラストの間がほぼ空の行で探し、装飾が濃く掛かっていて見つからない場合は
ゆるい閾値でもう一度探す（`フクロウ1` のように効果線がセリフの高さまで届くケース）。
