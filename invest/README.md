# 投資情報ウォッチ

主要マーケットの値動きと、投資判断に関わるニュースを1枚にまとめる個人用サイト。
GitHub Actions が平日2回（日本時間 7:40 と 15:50）に動き、値動きの取得・ニュース収集・
要約・ページ生成までを自動で行う。出力は `docs/invest/`。

```
invest/config.mjs      指標・ウォッチ銘柄・カテゴリ・情報源。ふだん触るのはここだけ
invest/build.mjs       取得 → 要約 → HTML生成をつなぐ入口
invest/preview.mjs     作り物のデータで見た目だけ確認する
invest/selftest.mjs    外部ネットワーク不要の自己テスト
invest/lib/market.mjs  値動きの取得（Yahoo Finance、予備に Stooq）
invest/lib/collect.mjs ニュースの収集と採否、ウォッチ銘柄の印付け
invest/lib/summarize.mjs 要約（Claude／鍵が無いときは本文からの抽出）
invest/lib/render.mjs  HTML生成
data/invest-archive.json 集めた記事の蓄積（コミットされる）
data/invest-market.json  直近の値動き（取得に失敗したときの前回値にも使う）
```

フィードの解析・本文の取り出し・Google ニュースの元URL解決は、防衛施設ウォッチ
（`news/lib/`）の部品をそのまま使っている。

## 画面

上から順に並ぶ。

1. **マーケット** … 日本株・米国株・為替と金利・商品と暗号資産の12指標。現在値、前日比、
   直近3ヶ月の推移、1週・1ヶ月・年初来の騰落率、52週の高値と安値のどこにいるか。
   グラフに触れるとその日の終値が出る。
2. **今日の要点** … 値動きとニュースから、押さえるべき動きを3〜5点に。
3. **ウォッチ銘柄** … 自分で決めた銘柄の値動きと、その銘柄が出てくるニュース。
   「n件」を押すとニュース一覧がその銘柄に絞られる。
4. **ニュース** … 直近3日分。1件ごとに3行要約、市場への影響、向き（▲追い風／▼向かい風／－中立）、
   関係する銘柄・資産が付く。カテゴリ・向き・銘柄・注目のみ・キーワードで絞り込める。

値の上下は、日本の証券会社に多い「上昇＝赤、下落＝青」で塗っている。色だけに頼らず、
必ず ▲▼ と符号を付けている。海外式（上昇＝緑）にしたいときは `site.upDownStyle` を
`'global'` にする。明暗はOSの設定に合わせて切り替わる。

## 公開

防衛施設ウォッチと同じ `docs/` の下に出すので、Pages の設定はそのまま使える。
公開URLは `https://<ユーザー>.github.io/<リポジトリ>/invest/`。

さくらインターネットに置いている場合は、`docs/` ごと取り込まれるので追加の作業は要らない。
`https://<設置先>/invest/` でログイン後に見られる（`server/public/gate.php` に許可を追加済み）。

要約に Claude を使うには、**Settings → Secrets and variables → Actions** に
`ANTHROPIC_API_KEY` を登録する（防衛施設ウォッチと共通）。未登録でも動くが、
要約は本文からの抜き出しになり、「影響」の行は出ない。

**注意:** GitHub は既定ブランチにあるワークフローしか定期実行・手動実行しない。
このブランチを既定ブランチに取り込むまでは、このブランチへの push でのみ走る。

## 追う内容を変える

すべて `invest/config.mjs`。

### ウォッチ銘柄

`watchlist` に足す。`yahoo` は Yahoo Finance のシンボル（東証は `7203.T` の形、米国株は
ティッカーそのまま）。`aliases` にニュースで使われる呼び名を入れると、その語が出た記事に
銘柄の印が付く。銘柄ごとの Google ニュース検索も自動で情報源に加わる。

```js
{ code: '6861', name: 'キーエンス', yahoo: '6861.T', stooq: '6861.jp', aliases: ['キーエンス'], digits: 0, unit: '円' },
```

### 指標

`markets` に足す。`group` が同じものが1段にまとまる。

### ニュースの採否

`keywords.market` のどれかが見出しか説明文の頭に出た記事だけを採る。経済面のフィードにも
新商品の発売や人事の記事が載るため。拾いすぎるなら語を減らすか `exclude` に足し、
取りこぼすなら `market` に足す。`strong` の語は注目度の点数を上げる。

### 情報源

`sources` に RSS を足すか、`googleNews('検索語')` を足す。日銀のように全件が材料になる
一次情報は `acceptAll: true` にするとキーワード判定を通さずに採る。

## 手元で動かす

```bash
npm ci
npm run invest:test      # 自己テスト（ネットワーク不要）
npm run invest:preview   # 作り物のデータで dist-invest-preview/ に出力
npm run invest:dry       # 取得と要約だけ試す。ファイルは書かない
npm run invest:build     # docs/invest/ と data/invest-*.json を生成
node invest/build.mjs --no-llm   # Claude を使わずに組む
```

## 値動きのデータについて

Yahoo Finance のチャートAPIから1年分の日足を取り、落ちたときは Stooq の日足CSVで
拾い直す。どちらも公式に保証された API ではなく、**値は15〜20分以上遅れる**。
どちらも取れなかった指標は、前回取れた値を点線の枠で「前回値」として出す。
一度も取れていない指標は「取得できませんでした」になる。

## うまく動かないとき

ページ下部の「情報源の取得状況」と、GitHub Actions の実行サマリに結果が出る。

- **指標が軒並み「前回値」** … Yahoo と Stooq の両方に弾かれている。実行ログの
  「値動き」の行に理由が出る。429 なら時間を置けば戻る。
- **特定の情報源が × のまま** … フィードの場所が変わったか廃止された。`urls` に候補を足すか行ごと消す。
- **関係ない記事が混ざる** … `keywords.market` の語が広すぎる。`exclude` に足す。
- **ウォッチ銘柄に関係ない記事が付く** … `aliases` に短すぎる語が入っている。

## 免責

公開情報を自動で集めて要約したもので、投資の勧誘や売買の推奨ではない。要約は誤ることがある。
判断は必ず原文と一次情報で確かめること。
