# Beauty Produce WordPressテーマ

このテーマは、Beauty Produceの公式サイトをWordPressで編集・更新できるようにしたオリジナルテーマです。トップページ、10代〜20代・30代・40代・50代〜60代の年代別ページ、サービス一覧、ビフォーアフター、お客様の声、FAQ、問い合わせフォームに対応しています。

## インストール手順

| 手順 | 操作 |
|---|---|
| 1 | このフォルダを `beauty-produce-wordpress-theme.zip` としてZIP圧縮します。 |
| 2 | WordPress管理画面で **外観 → テーマ → 新しいテーマを追加 → テーマのアップロード** を開きます。 |
| 3 | ZIPを選択してインストールし、**有効化**します。 |
| 4 | 有効化と同時に、ホームページ・4つの年代別ページ・サンプルのサービス／FAQ／お客様の声／ビフォーアフターが自動で作成されます。 |
| 5 | **設定 → パーマリンク** を開き、何も変更せずに「変更を保存」を一度押します。 |
| 6 | **外観 → カスタマイズ → Beauty Produce：基本情報** でブランド名、電話番号、メールアドレス、Instagram、メインイラスト、予約URLを設定します。 |

サンプルデータは実際の内容に書き換える前提で入っています。不要なものは各投稿タイプの一覧からゴミ箱へ移動してください。

## 日常的な編集場所

| 変更したい内容 | WordPress管理画面での操作 |
|---|---|
| ブランド名・連絡先・トップメッセージ・メインイラスト・予約URL | **外観 → カスタマイズ → Beauty Produce：基本情報** |
| 年代別ページの見出し、説明、お悩み、おすすめサービス、シーン | **固定ページ → 対象年代ページを編集 → 年代ページ：編集項目** |
| 年代別ページのヒーローイラスト | **固定ページ → 対象年代ページを編集 → アイキャッチ画像** |
| トップの8つのサービス | 管理画面左メニューの **サービス** |
| ビフォーアフター | 管理画面左メニューの **ビフォーアフター事例**。Afterはアイキャッチ画像、Beforeは編集欄の画像URLで設定します。掲載許可済みの画像のみ使用してください。 |
| お客様の声 | 管理画面左メニューの **お客様の声**。実際に許諾を得た感想のみ登録してください。 |
| FAQ | 管理画面左メニューの **よくある質問** |
| 並び順 | 各投稿の **ページ属性 → 順序** の数字が小さいものから表示されます。 |

## 「お悩み」「シーン」の入力形式

年代ページの「よくあるお悩み」「活躍するシーン」は、1行につき1件を次の形式で入力します。

```
見出し | 説明文
```

例：

```
20代の服が、急に似合わなくなった | 素材と丈のバランスが変わるタイミングです。骨格に合う質感に置き換えるだけで印象が戻ります。
朝、着る服を決めるのに時間がかかる | 着回しの型を決めてしまえば、考える時間はほとんど要らなくなります。
```

説明文を省略して、見出しだけを書くこともできます。

## 新しい年代ページを増やすには

1. **固定ページ → 新規追加** でページを作成します。
2. 右側の **ページ属性 → テンプレート** で **年代別ページ** を選びます。
3. 本文下の **年代ページ：編集項目** に、英字ラベル・年代の表記・キャッチコピーなどを入力します。
4. 公開すると、トップページの「年代から選ぶ」と各ページの「他の年代」に自動で追加されます。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `style.css` | テーマ情報と全ページのスタイル |
| `functions.php` | カスタム投稿タイプ、カスタマイザー、初期ページ生成、問い合わせフォームの処理 |
| `header.php` / `footer.php` | ヘッダーとフッター |
| `front-page.php` | トップページ |
| `page-stage.php` | 年代別ページのテンプレート |
| `index.php` | 投稿・アーカイブ・404などの汎用テンプレート |
| `template-parts/` | サービス、年代、流れ、ビフォーアフター、お客様の声、FAQ、フォーム、CTAの各セクション |
| `assets/js/theme.js` | ヘッダー、メニュー、スクロール表示、FAQ、比較スライダーの動作 |

## 注意事項

問い合わせフォームは、WordPressが設定している管理者メールアドレス（**設定 → 一般 → 管理者メールアドレス**）へ送信します。本番公開前にテスト送信を行い、メールが受信できることをご確認ください。メールが届かない場合は、SMTP設定用のプラグインの導入をご検討ください。

このテーマはWordPress 6.4以降、PHP 8.0以降を推奨します。予約を外部サービスで受ける場合は、カスタマイザーの「予約ページURL」に外部予約ページのURLを設定してください。空欄のときは、ページ内の問い合わせフォームへ移動します。
