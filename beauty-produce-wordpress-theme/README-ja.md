# Beauty Produce WordPressテーマ

美容プロデュースサービス「Beauty Produce」公式サイトのオリジナルテーマです。
トップページ、ライフステージ別ページ（10代〜20代／30代／40代／50代〜60代）、提供サービス、変化の物語（ビフォーアフター）、お客様の声、サービスの流れ、よくあるご質問、ご予約フォームに対応しています。プラグインは不要です。

## インストール手順

| 手順 | 操作 |
|---|---|
| 1 | このフォルダを `beauty-produce-wordpress-theme.zip` としてZIP圧縮します。 |
| 2 | WordPress管理画面で **外観 → テーマ → 新しいテーマを追加 → テーマのアップロード** を開きます。 |
| 3 | ZIPを選択してインストールし、**有効化**します。 |
| 4 | 有効化と同時に、ホームページ・4つのステージページ・サンプルデータ（サービス8種／FAQ／お客様の声／ビフォーアフター）が自動で作成されます。 |
| 5 | **設定 → パーマリンク** を開き、何も変更せずに「変更を保存」を一度押します。 |
| 6 | **外観 → カスタマイズ → Beauty Produce：基本情報** でブランド名、キャッチコピー、実績の数値、連絡先、Instagram、メインイラストを設定します。 |

サンプルデータは実際の内容に書き換える前提で入っています。不要なものは各投稿タイプの一覧からゴミ箱へ移動してください。

## 日常的な編集場所

| 変更したい内容 | WordPress管理画面での操作 |
|---|---|
| ブランド名・トップの大見出し・メッセージ・実績3項目・連絡先・メインイラスト | **外観 → カスタマイズ → Beauty Produce：基本情報** |
| ブランドメッセージ（「美容サロンではなく…」の帯） | 同上（「ブランドメッセージ見出し」「本文」「飾り文字」） |
| ステージページの英字ラベル・キャッチコピー・説明・お悩み・サービス・シーン | **固定ページ → 対象ページを編集 → ライフステージページ：編集項目** |
| ステージページのヒーローイラスト | **固定ページ → 対象ページを編集 → アイキャッチ画像** |
| 提供サービス（8種） | 管理画面左メニューの **サービス** |
| 変化の物語 | 管理画面左メニューの **ビフォーアフター**。Afterはアイキャッチ画像、Beforeは編集欄の画像URLで設定します。掲載許可済みの画像のみ使用してください。 |
| お客様の声 | 管理画面左メニューの **お客様の声**。実際に許諾を得た感想のみ登録してください。 |
| よくあるご質問 | 管理画面左メニューの **よくあるご質問** |
| 並び順 | 各投稿の **ページ属性 → 順序** の数字が小さいものから表示されます。 |

## 各投稿タイプの入力項目

| 投稿タイプ | タイトル | 本文 | 追加項目 |
|---|---|---|---|
| サービス | サービス名 | 説明文（1〜2行） | アイコン（絵文字1つ） |
| ビフォーアフター | ラベル（例：ファッション提案） | 説明文 | Before画像URL／After画像URL（任意） |
| お客様の声 | お名前の表記（例：S.K様） | ご感想 | 年齢／利用サービス／評価（1〜5） |
| よくあるご質問 | 質問文 | 回答文 | なし |

## ステージページの入力形式

**こんなお悩みはありませんか？** は、1行につき1件を入力します。

```
20代の頃に似合っていた服が、急に浮いて見えるようになった
朝、着る服を決めるのに時間がかかってしまう
```

**シーン別スタイリング** は、1行につき1件を「見出し | 説明文」の形式で入力します。

```
オフィス・商談 | 信頼感が伝わる配色とシルエットを選びます。
保護者会・入園式 | 浮かず、地味すぎず。場に馴染む上品さを。
```

**トップの大見出し**と**ブランドメッセージ見出し**は、改行で2行に分けると2行目が自動でブランドカラーの斜体になります。

## 新しいステージページを増やすには

1. **固定ページ → 新規追加** でページを作成します。
2. 右側の **ページ属性 → テンプレート** で **ライフステージ別ページ** を選びます。
3. 本文下の **ライフステージページ：編集項目** に、英字ラベル・年代の表記・キャッチコピーなどを入力します。
4. 公開すると、ヘッダーメニュー・トップの「あなたのステージを選んでください」・フッターに自動で追加されます。

## 注意事項

予約フォームは、WordPressが設定している管理者メールアドレス（**設定 → 一般 → 管理者メールアドレス**）へ送信します。
本番公開前にテスト送信を行い、メールが受信できることをご確認ください。届かない場合は、SMTP設定用のプラグインの導入をご検討ください。

このテーマはWordPress 6.4以降、PHP 8.0以降を推奨します。
外部の予約サービスを使う場合は、カスタマイザーの「予約ページURL」にそのURLを設定してください。空欄のときは、ページ内の予約フォームへ移動します。
