# 施工管理会社サイト（動きのあるコーポレートサイト）

建築の施工管理会社向けに作った、スクロール連動アニメーション中心の1ページ構成サイトです。
**ビルド不要・依存ライブラリなし**の素の HTML / CSS / JavaScript だけで動きます。

```
construction/
├── index.html              全セクションのマークアップ
├── assets/css/style.css    デザイン・アニメーション
└── assets/js/main.js       ローディング・スクロール連動などの制御
```

## 見る

```bash
# リポジトリのルートで
python3 -m http.server 8000
# → http://localhost:8000/construction/
```

`index.html` をブラウザに直接ドロップしても動きます（file:// でも可）。
Vite ビルド（`npm run build`）とは経路が分かれているので、React 版のサイトには影響しません。

## 画面の構成

| # | セクション | 動き |
|---|---|---|
| — | ローディング | 0→100% のカウンターと、下から閉じるカーテン |
| — | ヒーロー | 街並み・クレーン・光の3層パララックス、見出しの一文字送り、走査線、JST時計 |
| — | 流れる帯 | キーワードの無限マーキー |
| 01 | ABOUT | スクロールに合わせて本文が一節ずつ濃くなる／実績数値のカウントアップ |
| 02 | SERVICE | 行にホバーすると黄色が下から立ち上がり、文字色が反転 |
| 03 | WORKS | 縦スクロールを横移動に変換する固定表示ギャラリー（進捗バー付き） |
| 04 | FLOW | スクロールに追従して縦線が伸び、通過したステップの点が点灯 |
| 05 | RECRUIT | 斜めストライプ背景のパララックスと見出しの文字送り |
| 06 | CONTACT | ラベルが上に逃げる入力欄＋必須チェック |
| — | フッター | 社名の大型マーキー、トップへ戻る |

そのほか全画面: カスタムカーソル（PCのみ）、ページ上部の進捗バー、下スクロールで隠れるヘッダー、
モバイルの全画面メニュー、ボタンがカーソルに吸い寄せられるマグネット効果。

`prefers-reduced-motion: reduce` の環境ではアニメーションを止め、WORKS も通常の横スクロールに切り替えます。

## 差し替えるところ

内容はすべてサンプルです。公開前に次を実際の情報に置き換えてください。

- **会社名**: 「株式会社ミライ建設マネジメント / MIRAI CONSTRUCTION MANAGEMENT」（`index.html` 全体、`<title>` と footer）
- **連絡先**: `03-0000-0000` / `info@example.com` / 住所（CONTACT セクションとメニュー下部）
- **数字**: 実績1,280件・有資格者86名・稼働42現場・創業38年（`data-count` 属性）／採用の残業時間など
- **施工実績**: WORKS の6件。写真を使う場合は `.work__visual` の中身を `<img>` に差し替えると、
  CSSのグリッド演出はそのまま写真の上に重ねられます。
- **フォーム**: 送信先が未設定のため、いまは入力チェックのみで送信しません。
  `assets/js/main.js` の「9. お問い合わせフォーム」で、`fetch()` によるフォームAPI送信や
  `<form action>` でのメール送信に差し替えてください。
- **配色**: `assets/css/style.css` 冒頭の `--accent`（セーフティイエロー）などの変数。

## 補足

- フォントは Google Fonts（Anton / Noto Sans JP / Shippori Mincho）を読み込みます。
  社内ネットワークなど外部を参照できない環境では、フォントファイルを同梱して `@font-face` に置き換えてください。
- 画像を1枚も使っていないため、追加のアセットなしでそのまま静的ホスティング（Netlify / Vercel / S3 など）に置けます。
