# 福岡市長選ガイド
- index.html: 単一ファイルのサイト (HTML/CSS/JS、SVG地図込み)。元はClaude Artifact。
- data/: Artifact DBの events コレクションの控え (e001〜, ig001〜)。公開時は DB から読む実装。ローカルでは index.html 内の EVENTS0 にフォールバック。
- ルール: 全13候補を同じ項目・五十音順で扱う。場所と日付は推測しない(不明は「日付未確認」)。「—」(em-dash)は使わない。
- デザイン: 紙色 #f4efe3 / 墨 #26221c / 朱 #c4311e、角丸なし、ライトテーマ固定。
- 候補者の札の色は識別用に割り当てたもので公式色ではない。
