札の文字は候補者の姓の頭文字、色は候補者ごとの目印です(陣営の公式色とは限りません)。札の右上の数字は、その場所での活動が複数あるときの件数。区を押すと拡大して、その区の活動だけを表示します。「これまで全部」で候補者を選ぶと、日付順に点線で結びます(同じ日の順序は不明)。

    日程

    11月1日告示。立候補届出を受け付け、正式な候補者が確定します。

    このサイトについて

    2026年10月25日時点の情報です。

    掲載したのは、西日本新聞が10月20日時点で伝えた立候補予定者13人です。正式な候補者は11月1日の届出で確定します。NPO法人代表の永澤幹太氏は9月に出馬意向を示しましたが、供託金を10月31日までに確保できなければ見送ると本人サイトで説明しており、現時点の扱いを確認できていないため一覧に含めていません。

    告示前の今は、日々の予定を公表している陣営が限られます。地図に載せているのは、報道と、各候補者の公式サイトの活動欄で日付と場所が確認できたものだけです。Instagramは、公式アカウントの投稿画面で日付と場所が確認できたものを追加しています(確認できたのは一部の候補者のみ)。日付が画面で確認できないものは、その旨を表示しています。

    候補者の評価や順位づけはしていません。政策の詳細、費用、財源は各陣営の公式発表で確かめてください。
