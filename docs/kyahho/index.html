サービス内容

毎日のごはんを、 まるごと、ちょっとずつ。

きゃっほーは、料理に特化した家事代行です。献立を考えるところから、つくる、盛りつける、片づけるまで。全部でも、ひとつだけでも。ご希望に合わせて内容を決めていきます。

  • 作り置き

    数日分のおかずを、まとめてつくります。忙しい平日も、冷蔵庫を開ければごはんがある安心を。

    • 主菜・副菜の作り置き
    • 保存容器への小分け
    • 食べるときの温め方のメモ

    品数・日数はご相談ください

  • 夕食づくり

    その日の夕ごはんを、つくりたてでご用意します。帰ったら、あとは食卓につくだけ。

    • その日の夕食の調理
    • ご家族の人数に合わせた量
    • 食卓への盛りつけ

    時間帯・品数はご相談ください

  • 献立の相談

    好きなもの、苦手な食材、食べる人数などをお聞きして、献立を一緒に考えます。

    • 好みや苦手な食材の確認
    • 1週間分の献立づくり
    • 旬の食材を使った提案

    食物アレルギーへの対応はご相談ください

  • 食材の用意

    食材の買い出しから頼むか、ご用意いただいた食材でつくるか。ご都合に合わせてご相談ください。

    • 食材の買い出し
    • 冷蔵庫にある食材での調理
    • 使いきりたい食材の活用

    買い出しの有無・費用の扱いはご相談ください

  • 調理後のあと片づけ

    つくったあとの洗い物や、調理器具の片づけまで。料理を終えた台所を、使う前の状態に戻します。

    • 調理器具・食器の洗い物
    • 調理台・コンロまわりの拭き上げ
    • もとの場所への収納

    対応範囲はご相談ください

  • 特別な日のごはん

    誕生日や記念日、人が集まる日のごはんも。「こんな料理も頼めるかな？」と思ったら、まずは気軽に聞いてみてください。

    内容をご相談ください

きゃっほーが選ばれる理由

料理だけに、 しぼりました。

  1. 01

    料理に特化したサービス

    きゃっほーがお手伝いするのは、料理まわりの家事だけです。献立から調理、あと片づけまで、毎日のごはんのことをまとめて相談できます。

  2. 02

    自分の時間が生まれる

    ごはんづくりをおまかせしている時間は、まるごとあなたのもの。出かけても、家でのんびりしても大丈夫です。「台所に立つ時間」を「自分の時間」へ。

  3. 03

    希望に合わせて相談できる

    「今週は作り置きだけ」「薄味にしてほしい」「子どもが食べやすいように」など、その時々のご希望をお聞きして内容を決めます。決まったプランに合わせていただく必要はありません。

  4. 04

    安心しておまかせいただくために

    調味料や調理器具の置き場所、使ってほしくない道具、苦手な食材など、お家ならではのルールは事前にお聞きします。不安なことや気になることは、ご依頼の前に何でもご相談ください。
