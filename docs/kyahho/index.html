サービス内容

台所のことを、 一品ずつ、おまかせ。

きゃっほーは、料理に特化した家事代行です。献立を考えるところから、つくる、盛りつける、片づけるまで。全部でも、ひとつだけでも。ご希望に合わせて内容を決めていきます。

おしながき

きゃっほー

  • 作り置きご相談

    数日分のおかずを、まとめてつくります。忙しい日も、冷蔵庫を開ければごはんがある安心を。

    例主菜・副菜の作り置き／保存容器への小分け／温め方のメモ

  • 夕食づくりご相談

    その日の夕ごはんを、つくりたてでご用意します。帰ったら、あとは食卓につくだけ。

    例その日の夕食の調理／人数に合わせた量／食卓への盛りつけ

  • 献立の相談ご相談

    好きなもの、苦手な食材、食べる人数などをお聞きして、献立を一緒に考えます。

    例好みや苦手な食材の確認／数日分の献立づくり／旬の食材を使った提案

  • 食材の用意ご相談

    買い出しから頼むか、ご用意いただいた食材でつくるか。ご都合に合わせて決められます。

    例食材の買い出し／冷蔵庫にある食材での調理／使いきりたい食材の活用

  • 調理後のあと片づけご相談

    つくったあとの洗い物や、調理器具の片づけまで。料理を終えた台所を、使う前の状態に戻します。

    例調理器具・食器の洗い物／調理台・コンロまわりの拭き上げ

  • 特別な日のごはんご相談

    誕生日や記念日、人が集まる日のごはんも。「こんな料理も頼めるかな？」と思ったら、まずは気軽に聞いてみてください。

※値段の欄はすべて「ご相談」です。料金・品数・対応エリアは、ご希望をうかがったうえでご案内します。食物アレルギーへの対応も、事前にご相談ください。

きゃっほーが選ばれる理由

料理だけに、 しぼりました。

  • 料理に特化したサービス

    きゃっほーがお手伝いするのは、料理まわりの家事だけです。献立から調理、あと片づけまで、毎日のごはんのことをまとめて相談できます。

  • 自分の時間が生まれる

    ごはんづくりをおまかせしている時間は、まるごとあなたのもの。出かけても、家でのんびりしても大丈夫です。「台所に立つ時間」を「自分の時間」へ。

  • 好みに合わせて相談できる

    「今回は作り置きだけ」「薄味にしてほしい」「子どもが食べやすいように」など、その時々のご希望をお聞きして内容を決めます。決まったプランに合わせていただく必要はありません。

  • お家の台所のやり方で

    調味料や調理器具の置き場所、使ってほしくない道具、苦手な食材など、お家ならではのルールは事前にお聞きします。不安なことは、ご依頼の前に何でもご相談ください。

よくある質問

気になることを、先にどうぞ。

料金は、つくる品数や量、時間などによって変わります。ご相談の際に、ご希望をうかがったうえでご案内しますので、まずはお問い合わせください。

対応エリアについては、お問い合わせの際にご住所の地域をお知らせください。伺えるかどうかを確認してご連絡します。

作り置きのおかずや、その日の夕食づくりなど、毎日のごはんを中心に考えています。おしながきに載っていない料理も、お引き受けできるかどうかを含めてご相談ください。なお、きゃっほーは料理に特化したサービスのため、掃除や洗濯などはお引き受けしていません。

買い出しからおまかせいただく方法と、ご用意いただいた食材でつくる方法が考えられます。どちらがよいか、費用の扱いも含めてご相談ください。

事前に必ずお知らせください。お聞きした内容をもとに、お引き受けできる範囲をご相談させていただきます。

まずはご相談票からご連絡ください。内容の確認と日程の調整を経て、ご予約となります。どのくらい前までに連絡が必要かも、あわせてご案内します。

ご在宅・お出かけのどちらがよいかは、ご相談の際にお聞かせください。ご希望をうかがったうえで、対応できる方法をご案内します。
