# きゃっほー 公式サイト（料理の家事代行サービス）

作り置き・夕食づくり・献立の相談など、料理に特化した家事代行サービスのサイトです（掃除・洗濯などは扱わない前提）。

1ページで完結する静的サイトです。ビルド不要・依存ライブラリなし（HTML / CSS / 素のJavaScript）。
リポジトリ直下の美容サイト（Vite + React）とは独立しており、互いに影響しません。

```
docs/kyahho/
├── index.html      ページ本体（文言はすべてここ）
├── css/style.css   デザイン・アニメーション（色や文字は先頭の :root 変数で調整）
├── js/main.js      メニュー / FAQ / 相談フォーム / スクロール演出
└── favicon.svg
```

## 確認のしかた

```bash
cd docs/kyahho
python3 -m http.server 4173   # http://localhost:4173/
# または: npx serve .
```

`index.html` をブラウザで直接開いても表示できます。## 公開URL（GitHub Pages）

`docs/` は GitHub Pages で公開しているので、既定ブランチ（main）に入ると
`https://2kasa06.github.io/2kasa/kyahho/` で見られます。

ほかの静的ホスティングに置く場合も、このフォルダの中身をそのまま置けば動きます。

## デザインの考え方（2026年10月 作り直し）

taste スキルの手順で作り直し、web-design-guidelines スキルで確認しました。

- **読み取り**：30〜40代の共働き家庭に向けた生活サービスのLP。清潔で日常的なトーン。
- **ダイヤル**：レイアウトの崩し 6／動き 4／情報量 4。
- **色**：食卓に合う明るい配色に固定（ダークモードには切り替えない）。文字と線は黒ではなく深い青菜の緑（#24382B）、背景はやわらかな白と淡い若草色、アクセントはトマト色1色。
- **角丸**：ボタンは全丸、カードと写真は16px、入力欄は12px。
- **書体**：Zen Kaku Gothic New（本文・見出し）、Outfit（料金などの数字）。
- **アイコン**：Phosphor Icons（MIT）。使う10個だけのCSSとフォントを `vendor/phosphor/` に同梱しています。

| セクション | 内容 |
|---|---|
| ファーストビュー | 左に見出し「毎日のごはん、3日分ずつおまかせ。」、右に作り置きが並ぶ冷蔵庫の写真 |
| 1回で、3日分 | 週1回／週2回を切り替えると、1週間のどの日がそろうかが変わるカレンダー |
| プラン | 週1回（月額35,200円）と週2回（月額66,000円）、初回お試し6,600円 |
| 1回の中身 | 写真＋4マスのベント（3時間／主菜3・副菜6の目安／買い出し／保存のメモ） |
| 自分の時間 | 「家事」に線が引かれて「自分の時間に。」と読める見出し |
| 安心のために | アレルギー申告書・合鍵を預からない・写真で完了報告 |
| 流れ・FAQ・相談フォーム | 4ステップ、7問、メールアプリを開く形式のフォーム |

- 動きは IntersectionObserver と CSS だけ。scroll イベントは使っていません。`prefers-reduced-motion` では止まります。
- **写真について**：4枚の写真は画像生成（Higgsfield / GPT Image 2.5）で作ったもので、Higgsfield のCDNから直接読み込んでいます。CDNのURLが無効になると表示されなくなるため、公開前に画像ファイルを `img/` に保存して差し替えてください。読み込めないときも、レイアウトは崩れず色面だけが残ります。

## 仮置き（公開前に確認・差し替えが必要な箇所）

`index.html` 内の `<!-- 要確認 -->` コメントが目印です。

- **お問い合わせ先**：`info@example.com` は仮。フォームの `data-mailto` 属性とフッターのリンクの2か所。
- **相談フォームの送信方法**：送信先サーバーがないため、入力内容を本文に入れてメールアプリを開く方式。フォーム送信サービスを使う場合は `js/main.js` の「ご相談フォーム」部分を差し替え。
- **料金**：週1回35,200円・週2回66,000円・お試し6,600円・延長1,650円・買い出し1,100円は、事業スキームの試算にもとづく提案額。
- **1回分の目安**：「主菜3品・副菜6品（4人家族の夕食3日分）」「冷蔵で3日」は目安。社内で決まり次第書き換える。
- **写真**：生成画像を外部CDNから読み込み中。公開前に `img/` へ保存して差し替える。
- **食物アレルギー・食材の買い出し費用**：対応方針が未定のため「ご相談ください」の表現。
- **選ばれる理由 04（安心して任せられる）**：保険・研修・スタッフ体制などは未記載。事実として書ける内容が決まったら追記。
- **ご利用の流れ**：受付方法・事前確認の方法（訪問／オンラインなど）。
- **よくある質問**：料金・対応エリア・食材の用意・アレルギー・在宅の要否・利用頻度は、すべて「ご相談ください」の表現。「掃除や洗濯は引き受けていない」とだけ明記。
- **フッターの会社情報**：運営会社名・所在地・受付時間は「準備中」。
- 実績・口コミ・料金・資格・保険など、提供されていない情報は掲載していません。
