# チラシを配る前に片づけること

A4チラシをお客様に渡す前に、確認・確定が必要な項目です。
チェックを付けながら進められる版：https://claude.ai/code/artifact/4485c503-7b6d-48f8-9dcc-76828a9ce1fc

必須 17件 / 全30件。

## 01. 事実確認

刷ってしまうと直せない項目。ここが全部埋まるまで入稿しない。

- [ ] **FACT-01 連絡先4件を実際の値に差し替える**（必須）
      現在は仮の値：TEL `090-0000-0000` / MAIL `info@beauty-produce.jp` /
      INSTA `@beauty.produce` / WEB `beauty-produce.jp`。4つとも実在しない。
- [ ] **FACT-02 ¥33,000 の条件を確定する**（必須）
      税込か／何が含まれるか／何回で完了するか／追加費用の有無。
      紙面には「表示価格は税込です」と明記してあるので、税抜ならこの注記も直す。
- [ ] **FACT-03 お客様の声2件の実在確認と掲載許諾**（必須）
      掲載中は「S.K様・28歳」「Y.N様・43歳」。実在するなら書面かメッセージで掲載の同意を取る。
      実在しないなら削除する。体験談は景品表示法の対象で、作り話は打消し表示では救えない。
- [ ] **FACT-04 サービス8項目を今すべて提供できるか**（必須）
      提供していないメニューは載せない。特に外部の手配が要る「プロカメラマン撮影」「アクセサリー提案」。
- [ ] **FACT-05 「複数回に分けて実施／完全予約制」が実運用と一致するか**（要確認）
- [ ] **FACT-06 5ステップの流れが実際のオペレーションと一致するか**（要確認）
      特に STEP05「撮影・記録」が全員に付くのか、オプションなのか。

## 02. 表記・法務

紙は取り消せない。数字と効果表現がいちばん危ない。

- [x] **LAW-01 「無料」表記をチラシから全削除**（対応済）
      バッジ・訴求文・STEP01 の3か所を修正済み。今後、文言を足すたびに再確認する。
- [ ] **LAW-02 実績数値・満足度・No.1 の類を載せない（載せるなら根拠資料を保管）**（必須）
      サイトに残っている「1,200+／98%／10年+」は根拠資料がないと景品表示法の優良誤認にあたりうる。
      チラシには意図的に入れていない。
- [ ] **LAW-03 薬機法：肌・体質・効果に踏み込む表現を入れない**（必須）
      現状は「似合う」「魅力」の範囲に収めてある。
- [ ] **LAW-04 事業者名・責任の所在を記載するか判断**（推奨）
- [ ] **LAW-05 キャンセルポリシー・支払い方法を載せるか判断**（推奨）
- [ ] **LAW-06 インボイス登録番号の記載を検討**（推奨）

## 03. 入稿データ

現在のPDFは「画面で見る用」。印刷所に出すには作り直しが要る項目がある。

- [ ] **DATA-01 塗り足し3mm付きPDFを作り直す**（必須）
      現在は仕上がりサイズ 210×297mm ちょうどで塗り足しなし。ヒーローの背景と下部の予約帯が
      用紙の端まで届くデザインなので、このまま断裁すると白フチが出る。`216×303mm` で書き出し直し。
- [ ] **DATA-02 断裁ズレを見込んだ安全余白の確認**（必須）
      仕上がり線から3mm以内に文字がないか。下部の連絡先バーが用紙下端に近い。
- [ ] **DATA-03 CMYK変換と色の確認**（要確認）
      現在はRGB。ローズ〜ブラウンのグラデーション（予約帯）はCMYKで沈みやすい。
- [ ] **DATA-04 最小文字サイズを実物で確認**（要確認）
      最小は注記の 5.6pt（約2mm）。
- [x] **DATA-05 画像解像度**（対応済）
      ステージ画像 約350dpi／ヒーロー 約320dpi。
- [x] **DATA-06 フォント埋め込み**（対応済）
      Zen Maru Gothic / Cormorant Garamond をサブセットで埋め込み済み。アウトライン化は不要。
- [ ] **DATA-07 イラスト6点の商用・印刷利用の権利を確認**（必須）
      Web用と印刷用でライセンスが分かれる素材がある。
- [ ] **DATA-08 誤字脱字を第三者に読んでもらう**（必須）

## 04. 印刷・仕上げ

- [ ] **PRINT-01 印刷会社を決め、入稿仕様を先に聞く**（必須）
      塗り足し幅・トンボの要否・カラーモード・入稿形式。
- [ ] **PRINT-02 紙・部数・仕上げを決める**（必須）
      コート紙／マットコート 90〜110kg が目安。
- [ ] **PRINT-03 家庭用プリンタでA4等倍の試し刷りをする**（必須）
- [ ] **PRINT-04 色校正を取るか判断**（推奨）

## 05. 導線とサイトの整合

チラシを見た人が次に触るのはサイト。ここが食い違うと信用を落とす。

- [ ] **WEB-01 QRコードを入れるか判断**（推奨）
      今はURLの文字列だけ。入れるなら下部の連絡先バー付近にスペースを作る。
- [ ] **WEB-02 サイトFAQの料金をチラシに合わせる**（必須）
      サイトは「¥50,000〜」のまま。チラシの ¥33,000 と食い違っている。
- [ ] **WEB-03 サイトの「無料カウンセリング」7か所を修正**（必須）
      `src/pages/Home.tsx:168` / `src/pages/AgePageTemplate.tsx:183` /
      `src/components/CommonSections.tsx:311, 427, 586, 665, 700`
- [ ] **WEB-04 サイトの実績数値の扱いを決める**（必須）
      「1,200+／98%／10年+」を実数に直すか、削除するか。
- [ ] **WEB-05 予約フォームの送信先を設定する**（必須）
      現状フォームは送信されず、画面に完了メッセージが出るだけ
      （`src/components/CommonSections.tsx:557` の `handleSubmit` が `setSubmitted(true)` のみ）。
      お客様は送ったつもりでも誰にも届かない。チラシを配る前に必ず塞ぐ。
- [ ] **WEB-06 特定商取引法に基づく表記ページを用意するか判断**（要確認）
