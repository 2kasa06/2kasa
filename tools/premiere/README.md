# プロフィールムービー用 Premiere Pro スクリプト

結婚式のプロフィールムービーで一番手間がかかる「写真を並べて、1枚ずつゆっくりズームを付ける」
作業を自動化する ExtendScript です。写真を差し替えても同じ編集を作り直せるようにするのが目的です。

```
tools/premiere/
├── profile-movie-builder.jsx   ← Premiere で実行するスクリプト
├── test/mock-test.mjs          ← Premiere なしで動作を検証するテスト
└── README.md
```

---

## 事前準備（ここを飛ばすと失敗します）

### 1. 静止画のデフォルトデュレーションを長くする

<kbd>環境設定 > タイムライン > 静止画のデフォルトデュレーション</kbd> を **10 秒** にします。

スクリプトは「長めに置いたクリップを次の1枚で上書きして切り詰める」方式で尺を作るため、
既定尺が `clipSeconds` より短いと隙間だらけになります。設定が短いまま実行した場合は
警告ダイアログが出て中断するので、無言で壊れることはありません。

> この設定は **読み込み時に固定** されます。すでに読み込み済みの写真には反映されないので、
> 設定を変えたら写真をプロジェクトから削除して読み込み直してください。

### 2. 写真を下ごしらえする

- 画素数とアスペクト比を揃える（**2560×1440 以上・16:9 推奨**）。ズームする余白が要ります
- ファイル名を `01.jpg` `02.jpg` … の連番にする。並び順がそのままカット順になります
- 連番は自然順で並ぶので、`1.jpg` と `10.jpg` が混ざっても `1 → 2 → 10` の順になります

### 3. シーケンスを作り、ビデオトラックを3本以上にしておく

スクリプトはシーケンスを作りません。**式場の指定に合わせて自分で作り**、タイムラインで
アクティブにしてから実行してください（フレームレートや解像度の指定は式場によって違います）。

既定では **V1 = ぼかし背景 / V2 = 写真本体 / V3 = 2分割の右側** を使うため、
ビデオトラックが3本以上必要です。足りない場合はトラックヘッダを右クリック >
トラックを追加（不足していれば実行前にダイアログで指摘します）。

## 使い方

1. Premiere Pro で目的のシーケンスを開く
2. <kbd>ファイル > スクリプト > スクリプトファイルを実行...</kbd>
3. `profile-movie-builder.jsx` を選ぶ
4. 写真フォルダを選択するダイアログが出るので、フォルダを指定する

これで V1 に写真が等間隔で並び、1枚ずつに Ken Burns が付きます。

### 尺を手で調整したあと、動きを付け直す

BGM に合わせてクリップの長さを手で変えると、キーフレームが尺に合わなくなります。
その場合はスクリプト冒頭の `mode` を `"motion"` に変えて再実行してください。
**配置には触れず、いま並んでいる尺に合わせてモーションだけを引き直します。**

## 編集リスト — カット割りを表で決める

`EDIT_LIST` に「どの写真を何秒」を並べます。既定では参考動画（1分26秒）の構成に
合わせてあり、曲の展開にパートが乗るようになっています。

| 位置 | 尺 | 内容 |
|---|---|---|
| 0:00 – 0:02 | 2.0秒 | オープニング（手作業。スクリプトはここを空けて始める） |
| 0:02 – 0:09 | 7.0秒 | キービジュアル |
| 0:09 – 0:15 | 6.0秒 | タイトル背景 |
| 0:15 – 0:43 | 4.0秒 × 7 | Aメロ。ゆっくり見せる |
| 0:43 – 1:09 | 3.3秒 × 8 | 大サビ。テンポを上げて畳みかける |
| 1:09 – 1:14 | 4.6秒 | **2分割**（縦写真2枚を左右に） |
| 1:14 – 1:19 | 5.0秒 | クライマックス。冒頭のキービジュアルに戻す |
| 1:19 – 1:26 | 7.0秒 | エンドカード（手作業） |

書き方は2種類です。

```js
{ file: "5.jpg", sec: 4.0, label: "Aメロ" }

{ split: [ { file: "19.jpg", scale: 133.3, y: -0.03 },
           { file: "20.jpg", scale: 118.5, y:  0.00 } ],
  sec: 4.6, label: "2分割" }
```

### 2分割の scale の決め方

`scale` は「フレームサイズに設定」を 100 としたときの倍率で、**表示幅がちょうど
画面の半分（1920px の半分 = 960px）になる値**を入れます。

```
scale = 100 × 960 ÷ (フレームに収めたときの表示幅)
```

この値にすると2枚が隙間なく隣り合い、はみ出しも重なりも起きないので、
クロップ効果もマスクも要りません。縦写真どうしの組み合わせが最も収まります。

`y` は上下の位置の微調整です（`-0.03` で画面の高さの3%ぶん上へ）。縦写真は
上下がはみ出るので、顔や足が切れるときにここで寄せます。

**2分割にはズームを付けません。**拡大すると隣の半分に重なってしまうためです。
動くカットの中で1枚だけ静止するので、かえって見せ場になります。

## 設定

`profile-movie-builder.jsx` の冒頭 `CONFIG` を書き換えます。

| 項目 | 既定 | 意味 |
|---|---|---|
| `mode` | `"build"` | `"build"` = 配置＋モーション / `"motion"` = モーションだけ付け直す |
| `useEditList` | `true` | `EDIT_LIST` のとおりに配置する。`false` なら並び順に等分 |
| `startSeconds` | `2.0` | 配置開始位置。冒頭にオープニング用の余白を空ける |
| `source` | `"folder"` | `"folder"` = フォルダ選択ダイアログ / `"selection"` = プロジェクトパネルの選択を使う |
| `clipSeconds` | `3.5` | `useEditList` が `false` のときの、1枚あたりの秒数 |
| `videoTrack` | `1` | 写真本体を置くトラック。`1` = V2（背景はその1つ下の V1 に入る） |
| `backgroundFill` | `true` | 16:9 でない写真の黒帯を、ぼかした同じ写真で埋める |
| `backgroundScale` | `250` | 背景の拡大率。ぼかすので大きめで構わない |
| `blurAmount` | `60` | ぼかしの強さ |
| `startAtPlayhead` | `false` | `true` なら再生ヘッド位置から。`false` なら `startSeconds` から |
| `kenBurns` | `true` | ズーム／パンを付けるか |
| `zoomPercent` | `8` | ズーム量。`100 → 108` なら `8` |
| `panPercent` | `1.2` | 横に振る量（画面幅に対する％）。`0` で横移動なし |
| `alternate` | `true` | 1枚おきにズームイン／アウトを交互にする |
| `easing` | `true` | 両端をベジェ補間にして滑らかにする |
| `scaleToFrameSize` | `true` | 「フレームサイズに設定」を自動適用する |

## スクリプトがやらないこと

Premiere の ExtendScript API では扱えない、または手でやったほうが早いものです。
配置が終わったら、この順で手作業を足してください。

| トラック | 内容 |
|---|---|
| **V7** | 調整レイヤー — 白フラッシュ、幾何ワイプなどの区切り演出 |
| **V6** | テキスト — エッセンシャルグラフィックス。「レスポンシブデザイン – 時間」でイン／アウトを固定する |
| **V5** | 装飾フレーム — シェイプ＋4色グラデーションをアルファマットで透かすと色が変化する枠になる |
| **V4** | 調整レイヤー1本を全長に敷き、Lumetri で全体のトーンを統一する |
| V3 | ← スクリプトが作る（2分割の右側。使うカットだけ） |
| V2 | ← スクリプトが作る（写真本体＋Ken Burns） |
| V1 | ← スクリプトが作る（ぼかし背景） |
| **A1** | BGM。<kbd>M</kbd> でサビ頭・間奏頭にマーカーを打ち、カット点をそこへ合わせる |

冒頭 0:00〜0:02 と、写真パートの終わり以降（既定では 1:19〜1:26）は
スクリプトが空けたままにするので、オープニングとエンドカードを置いてください。

### なぜ背景をぼかして敷くのか

スマホやSNS経由の写真は 4:3 や縦位置が多く、16:9 のシーケンスに置くと必ず黒帯が出ます。
帯を消すには写真を拡大してトリミングすることになりますが、元が小さい写真だと画質が落ち、
人物の頭や足が切れることもあります。

同じ写真を下に敷いて大きくぼかせば、**前面の写真を1ミリも拡大せずに**画面が埋まります。
背景の拡大率は写真ごとに計算せず一律 250% にしています。強くぼかすので、はみ出しても
見え方に影響しないためです。

## テスト

Premiere なしで、配置位置・尺・キーフレームの値を検証できます。
ExtendScript API をモックして、スクリプト本体をそのまま実行しています。

```bash
node tools/premiere/test/mock-test.mjs
```

検証している内容:

- 編集リストどおりの尺になり、全体が参考動画と同じ 0:02〜1:19 に収まること
- カット間に隙間も重なりも出ないこと
- 2分割の左右が同じ時間・同じ尺で並び、スケールと位置が半分ぴったりになること
- 2分割にはズームが付かないこと、その位置に背景を敷かないこと
- ズームイン／アウトが交互になり、キーフレーム時刻が各カットの尺に一致すること
- 編集リストの写真が足りないとき、名前を挙げて1枚も置かずに止まること
- 静止画のデフォルトデュレーションが短い場合に、警告して中断すること
- トラックが足りない場合に、必要な本数を示して実行前に止まること
- QE DOM が使えない環境でも、配置は成功させたうえでぼかしだけ手作業に回す案内が出ること
- `useEditList: false` のとき、従来どおり自然順ソートで等分されること

## 動作確認について

上のテストは Premiere の API をモックしたものです。**実機の Premiere Pro では未検証**なので、
最初は捨てて良いテスト用プロジェクトで試してください。特に次の3つはバージョン差が出やすい箇所です。

- `setInterpolationTypeAtKey` の補間タイプ番号（失敗してもリニアのキーフレームは残ります）
- QE DOM 経由の「フレームサイズに設定」とガウスブラーの追加
  （失敗した場合はダイアログで手作業を案内します）
- Motion コンポーネントの表示名。日本語版「モーション」と英語版「Motion」の両方を見ていますが、
  他の言語で使う場合はスクリプト内の `NAMES` に表示名を足してください
