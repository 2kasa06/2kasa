# 文字とエフェクトの仕様書

同梱の PNG をそのまま使う場合はこの書類は不要です。
**Premiere 上で編集できるテキストに置き換えたいとき**に、この数値どおりに
エッセンシャルグラフィックスで作り直してください。

書体はすべて Google Fonts（無料・商用可）です。同じものを使う場合は
それぞれインストールしてください。

| 用途 | 書体 | ウェイト |
|---|---|---|
| 筆記体の一言 | Parisienne | Regular |
| お名前・日付 | Cormorant Garamond | Light / Regular |
| 日本語 | Zen Kaku Gothic New | Light / Medium |

文字色は **#3A3A3A**（濃いグレー）。参考動画も黒ではなくグレーを使っています。
写真の上に出すキャプションだけ白 **#FFFFFF** です。

## 1. オープニングワイプ　0:00 – 0:02

白ベースに、白い帯が角度を変えながら4回横切ります。

| | |
|---|---|
| 帯の角度 | -28° / +34° / -16° / +22° の順 |
| 各帯の動き | 画面左外 → 右外。イーズイン／イーズアウト |
| ずれ | 0.1〜0.15 秒ずつ遅らせて発火 |

Premiere で作る場合は、白のカラーマットに **リニアワイプ** を角度違いで
4枚重ね、変換終了を 100 → 0 にキーフレームします。

## 2. タイトル　0:02 – 0:09（実際の表示は 2.6 – 8.6 秒）

写真を白いベールで飛ばした上に、濃いグレーの文字を置きます。

| 要素 | 内容 | 位置（画面比） | サイズ | 字間 |
|---|---|---|---|---|
| 白スクリム | 白・中心 52% / 周辺 80% の放射状 | 全面 | — | — |
| 一言 | Hello everyone | 中央 / 上から 34% | 112 px | 標準 |
| お名前 | NAME & NAME（大文字） | 中央 / 上から 42% | 150 px | **+18 px** |
| 罫線 | 横 300 px・1 px・不透明度 55% | 中央 / 上から 63.5% | — | — |
| 挙式日 | 2026.00.00 | 中央 / 上から 66% | 40 px | +8 px |

**お名前の字間を広く取るのがこの見た目の肝です。** 詰まっているとありふれた印象になります。

フェード: 前後 0.6 秒。スクリプトは不透明度を 0 → 100 → 100 → 0 で打ちます。
白スクリムの最大不透明度は 92%。

## 3. キャプション　各カットの頭から

写真ごとの日付と場所。左下に小さく置きます。

| 要素 | 位置 | サイズ | 色 |
|---|---|---|---|
| 短い罫線 | 左 110 px / 下から 312 px | 54 × 2 px | 白 78% |
| 日付 | 左 110 px / 下から 290 px | 44 px・字間 +5 | 白 |
| 場所 | 左 110 px / 下から 228 px | 40 px | 白 |

影: ぼかし 8 px・不透明度 59%・下に 2 px。写真が明るくても沈まないように。
フェード: 前後 0.4 秒。タイトルが出ている間は出しません。

## 4. 白フラッシュ　0:14.8 / 0:42.8 / 1:13.8

曲のパートが変わるところにだけ入れます。

| | |
|---|---|
| 長さ | 0.45 秒 |
| 不透明度 | 0 → 85% → 0（山なり） |

全カットの区切りに入れると忙しくなるので、この3か所だけにしてあります。

## 5. カラーフレーム　1:14 – 1:19

クライマックスの写真を囲む枠。色が流れるように変化します。

| | |
|---|---|
| 枠の位置 | 画面から 46 px 内側 |
| 線の太さ | 16 px |
| 色 | 左から右へ 黄 → ピンク → 紫。5秒で半周ぶん流れる |

Premiere で作る場合は、長方形シェイプ（塗りなし・境界線16px）を
**アルファマット**にして、上に置いた 4色グラデーションを透かします。
境界線の色は直接キーフレームできないためです。

## 6. エンドカード　1:19 – 1:26

| 要素 | 内容 | 位置 | サイズ |
|---|---|---|---|
| 背景 | 白 | 全面 | — |
| 枠 | 黄→ピンク→紫のグラデーション | 28 px 内側 | 14 px |
| 1行目 | Thank you for coming today | 中央 / 上から 44% | 96 px（筆記体） |
| 2行目 | このあともゆっくりお楽しみください | 中央 / 上から 58% | 44 px |

最後の 1.2 秒で黒へフェードアウトします。

## 文言を変えるとき

`テキスト設定.json` を書き換えて `python3 make_overlays.py` を実行すると、
PNG が作り直されます。Premiere 側は同じファイル名を読み直すだけなので、
配置もフェードもそのまま残ります。

Python が無ければ、変えたい文言を伝えてもらえれば作り直してお渡しします。
