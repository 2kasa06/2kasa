====================================================
手順
====================================================

1. フォントを4つ入れる
   fonts の中の4ファイルを選択 → 右クリック → インストール
   ※ OneDrive の中だと「インストール」が出ないことがあります。
     その場合は 設定 > 個人用設定 > フォント にドラッグ＆ドロップ。
   ※ 入れたあと After Effects を一度再起動してください。

2. After Effects を起動（プロジェクトは空でOK）

3. ファイル > スクリプト > スクリプトファイルを実行...
     wedding-opening.jsx を選ぶ
   写真フォルダを聞かれるので photos を指定

4. コンポジションが開きます
   全体が1つの取り消しにまとまっているので Ctrl+Z 一発で戻せます。

   ★ レイヤーが 300 枚を超えます。プレビューは画質を 1/2 か 1/4 に
     落としてから再生してください。

====================================================
直したいとき
====================================================

wedding-opening.jsx をメモ帳などで開くと、上のほうに設定があります。

  CONFIG
    ・新郎新婦が逆     → groom と bride の2行を入れ替える
    ・キューブの大きさ  → cubeSize（既定 300）
    ・回転の速さ       → cubeSpins（既定 1.6）
    ・羽の数           → feathers（既定 16）

  SCENES
    絵コンテそのものです。start と dur を変えれば尺が変わります。
    type を入れ替えれば入り方が変わります。使える type は
      hold / holdZoom / slideIn / cardFlip / wipeDiag / stripsIn /
      splitOpen / punchIn / tileRise / shutter / spinIn / flashCut /
      dropBounce / puzzleDrop / flipStrips / pinwheel / nameWhite /
      cubeBurst / splitPair / climax / endcard


====================================================
BGM
====================================================

音は入れていません。Premiere で仕上げるなら Dynamic Link が楽です。
  Premiere > ファイル > Adobe Dynamic Link >
             After Effects コンポジションを読み込み

市販曲を自作ムービーに使う場合は複製権の処理（ISUM 申請など）が
必要です。式場に早めにご相談ください。
