# 結婚式オープニングムービー / After Effects スクリプト

参考動画の演出体系を After Effects の中に**本物のレイヤーとして**組み立てます。
PNG を貼り込むのではないので、テキストは打ち直せますし、色も面の位置も
すべて AE 上で触れます。

```
tools/after-effects/
├── wedding-opening.jsx     ← AE で実行するスクリプト
├── test/mock-test.mjs      ← AE なしで動作を検証するテスト
└── README.md
```

## なぜ Premiere ではなく AE なのか

参考動画の演出は、Premiere で手作業する類のものではありません。

| 演出 | Premiere | After Effects |
|---|---|---|
| 1字ずつ飛び込む文字 | 1文字1レイヤーで手打ち | **テキストアニメーターで1行** |
| 面が滑り込む | シェイプ＋位置キーフレーム | 同じ（ただし生成が容易） |
| 写真のタイル分割 | 16レイヤーを手でマスク | **スクリプトで一括生成** |
| 全編のグリッド線 | 静止画を敷く | シェイプレイヤー |

AE の ExtendScript は Premiere と違い、テキスト・シェイプ・マスク・
キーフレームをすべてプログラムから作れます。だから丸ごと生成できます。

## 事前準備

### 1. フォントを入れる

`fonts/` の 4 書体をインストールしてください（すべて Google Fonts・商用可）。

| 用途 | 書体 |
|---|---|
| 英文（細い丸ゴシック系） | Quicksand Light / Medium |
| 筆記体 | Sacramento |
| 日本語 | Zen Kaku Gothic New Light |

入っていなければ代替を順に探し、無ければ AE の代替表示のまま完走します
（落ちません）。あとから AE 上で選び直せます。

### 2. お名前を書き込む

`wedding-opening.jsx` の冒頭 `CONFIG` を開いて、ここだけ埋めてください。

```js
groom: { romaji: "MASATO MURANO", kanji: "村野真人", label: "Groom" },
bride: { romaji: "KANA SUZUKI",   kanji: "鈴木佳奈", label: "Bride" },
date:  "2026.10.04",
```

**漢字の姓名が中盤の主役**です。1字ずつ独立したレイヤーになり、
上下に振りながら順に飛び込んできます。

## 使い方

1. After Effects を起動（プロジェクトは空でも構いません）
2. <kbd>ファイル > スクリプト > スクリプトファイルを実行...</kbd>
3. `wedding-opening.jsx` を選ぶ
4. 写真フォルダを指定する

コンポジションが1つでき、そのまま開きます。
全体が1つの取り消しにまとまっているので、気に入らなければ <kbd>Ctrl/Cmd+Z</kbd> 一発で戻せます。

## できあがる構成

| 位置 | 内容 |
|---|---|
| 0:00 – 0:02 | 白い帯が角度を変えて4回横切る |
| 0:02 – 0:14 | 写真（ゆっくりズーム） |
| 0:14 – 0:19 | Welcome to our wedding reception（1字ずつ立ち上がる） |
| 0:19 – 0:24 | **新郎**：モノクロ写真＋ベタ面が滑り込む＋漢字の姓名 |
| 0:24 – 0:43 | 写真 |
| 0:43 – 0:48 | **新婦**：同じ作りで左右を反転 |
| 0:48 – 1:01 | 写真 |
| 1:01 – 1:07 | 写真を4×4タイルに分割＋コーナーブラケット＋Groom and Bride |
| 1:07 – 1:09 | 写真 |
| 1:09 – 1:14 | 縦写真2枚を左右half |
| 1:14 – 1:19 | クライマックス＋色が変わる枠 |
| 1:19 – 1:26 | エンドカード → 黒へ |

全編に白いグリッド線と外枠が薄く乗ります（`CONFIG.gridOpacity` で濃さを調整）。

## 触りどころ

| やりたいこと | どこを触るか |
|---|---|
| 文言を変える | AE 上でテキストレイヤーを直接編集 |
| カット割り・尺を変える | `SCENES` 配列（`start` と `dur`） |
| 色を変える | `C` の magenta / purple / coral / gold |
| グリッド線を消す | `CONFIG.gridOpacity` を 0 に |
| モノクロをやめる | `CONFIG.monoSections` を false に |
| ズーム量を変える | `CONFIG.kenBurns`（既定 8%） |

`SCENES` は `type` で作りが決まります。
`photo` / `welcome` / `nameblock` / `tiles` / `split` / `climax` / `endcard` / `opening`。
順番を入れ替えたり、`nameblock` をもう1つ足したりできます。

## Premiere に持っていく

BGM と最終書き出しを Premiere でやりたい場合は **Dynamic Link** が楽です。

Premiere で <kbd>ファイル > Adobe Dynamic Link > After Effects コンポジションを読み込み</kbd>。
AE 側を直すと Premiere にそのまま反映されます。書き出す必要はありません。

## テスト

AE なしで、レイヤー構成・時間・キーフレーム・マスクを検証できます。
ExtendScript API をモックして、スクリプト本体をそのまま実行しています。

```bash
node tools/after-effects/test/mock-test.mjs
```

検証している内容:

- コンポの寸法・尺・fps、取り消しが1つにまとまること
- グリッドが最前面に薄く敷かれること
- オープニングの帯4枚が角度違い・時間差で抜けること
- Welcome が3行に分かれ、テキストアニメーターで1字ずつ出ること
- ベタ面が画面外から滑り込むこと、漢字が1字1レイヤーで上下に振れること
- タイルが4×4=16枚に割れ、各々にマスクが入り、時間差で立ち上がること
- 2分割が左右にマスクされ外側から滑り込むこと
- 枠の色が3点で変化し、最後が黒に落ちて 86.0 秒で終わること
- 全キーフレームにイーズが掛かること
- 写真の欠品・フォルダのキャンセル・フォントなし・古い AE での縮退動作

---

## 実機では未検証です

上のテストは AE の API をモックしたものです。**実機の After Effects では未検証**なので、
最初は空のプロジェクトで試してください。バージョン差が出やすいのは次の3点です。

- テキストアニメーターのマッチ名（`ADBE Text Animator` 系）
- `app.fonts`（新しめの AE のみ。無い場合は代替名をそのまま渡します）
- モノクロ効果のマッチ名（`ADBE Black&White` → 無ければ `ADBE Tint` を試します）

いずれも try で包んであり、失敗しても組み立て自体は最後まで走ります。
